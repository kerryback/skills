# human-write

Write and edit prose that reads as human rather than machine-generated.

Not a style guide bolted on after the fact — it changes how the sentences come
out in the first place. Varied rhythm, no formulaic tells, and structure that
follows the argument instead of a template.

## Install

```
/plugin marketplace add kerryback/skills
/plugin install human-write@kerryback
```

It applies when you're drafting and when you're revising, and triggers on
"make this sound less like AI" as well as on ordinary writing requests.

## What it's actually fixing

AI prose reads uniform. Every sentence lands at about the same length, every
paragraph opens the same way, and every section arrives at a tidy three-item
list. Individually nothing is wrong; cumulatively it is unmistakable.

The skill names the specific tells — the delve vocabulary, however at every
turn, the not-X-but-Y contrast, the compulsory triple — and, more usefully, says
what to do instead. It includes before-and-after passages, because the failure
is easier to see than to describe.

## Register

The default is scholarly: journal articles, working papers, referee reports,
grant proposals. That is a default rather than a limit — it handles other
registers when you ask, but it will not make an economics paper chatty because
nobody asked it to.

## Two moments, same principles

Drafting and editing use the same rules. Editing is harder, because a draft with
the tells in it has already shaped the argument around them, and pulling one
sentence back into human rhythm sometimes means rebuilding the paragraph around
it. The skill treats that as expected rather than as a failure.
